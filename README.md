# English Grammar Assessment — 40 Questions

A static, browser-based English grammar test focused on Past Simple, Past Participle and Present Perfect, with reading comprehension, paragraph completion, sentence transformations and listening. No backend, API key, build tools or paid dependencies are required.

## Run locally
Open `index.html` in a modern browser. Listening uses the browser’s built-in speech synthesis, where available.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `README.md` directly to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. Wait for GitHub Pages to publish the site and open the URL shown in the Pages settings.

All resources use relative paths; this project has no external asset dependencies.
